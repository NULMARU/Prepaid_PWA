밥장부 도움말

처음 쓰는 순서, 자주 묻는 질문, 의견 보내는 곳을 한 쪽에 모았어요. 짧은 설명은 첫 화면에 있어요.

  • 음식점 사장님 안내서
  • 공공기관 담당자(서무) 안내서
  • 직원 안내서

시작부터 식사까지 5단계

사장님이 앱을 설치하고 우리 가게 등록을 마치면, 공공기관 담당자(서무)가 선금 명단을 보내요. 사장님이 받은 금액을 확인하면 바로 직원 사용이 시작돼요. 회사(사기업)·개인 선금은 이 흐름을 거치지 않고 사장님이 앱에서 직접 등록하면 돼요.

  1. 음식점 사장님이 해요

    앱 설치

    app.bapjangbu.com에 접속해 홈 화면에 추가해요. 안드로이드는 크롬에서 [홈 화면에 추가](없으면 ⋮ 메뉴 → [홈 화면에 추가] 또는 [앱 설치]), 아이폰·아이패드는 사파리의 공유 버튼 → [홈 화면에 추가]. 그다음부터는 홈 화면의 ‘밥장부’ 아이콘으로 열어요.

  2. 음식점 사장님이 해요

    우리 가게 등록

    공공기관 명단을 받으려면 필수예요. 가게 이름으로 찾아 등록해야 공공기관 담당자(서무)가 우리 가게를 찾을 수 있어요.

    회사(사기업)·개인 선금만 받으신다면 이 등록 없이도 수동 등록으로 바로 장부를 쓸 수 있어요.

  3. 공공기관 담당자(서무)가 해요

    음식점 선택과 명단 작성

    agency.bapjangbu.com에서 등록된 음식점을 고르고(여러 곳을 한 번에 고를 수 있어요), 직원 명단과 금액을 입력해요.

  4. 공공기관 담당자(서무)가 해요

    선금 명단 전달

    명단은 암호화되어 음식점 앱으로 전달돼요(바로 보내기 또는 담당자 전달파일·QR). 음식점 앱에서는 자동 등록 — 공공기관에서 보낸 명단 받기로 도착해요. 선금(돈)은 앱 밖에서 음식점에 직접 지급해요. 여러 음식점에 보낼 때도 음식점마다 따로 지급해요.

  5. 음식점 사장님이 해요

    받은 금액 확인, 그리고 직원 사용 시작

    명단에 적힌 금액을 실제로 받으셨는지 확인한 뒤 장부에 올리세요. 카드로 받으셨다면 카드 단말기 매출전표·POS 매출 내역에서 금액과 승인일시를, 계좌이체로 받으셨다면 통장 입금 내역에서 입금자명과 금액을 맞춰 보면 돼요. 제로페이로 받으셨다면 가맹점 앱 정산 내역이나 통장 입금 내역을 보세요. 여러 부서 명단이 왔는데 받은 돈이 한 건이라면 명단 여러 건의 합계와 맞춰 보세요.

    확인이 끝나면 사용을 시작해요. 식사 때 직원 이름과 금액을 확인해 사용 기록을 저장하면 잔액에서 차감돼요.

    바쁠 때는 손님이 직접 태블릿에서 이름을 찾아 금액·서명까지 해 두고, 사장님은 확인만 하면 돼요. (손님 셀프 조회 안내)

돈은 앱 밖에서 움직여요. 밥장부 안에서는 돈이 오가지 않아요. 선금(돈)은 기관과 음식점이 앱 밖에서 직접 주고받고, 앱이 받는 것은 암호화된 직원 명단뿐이에요. 여러 음식점에 명단을 한 번에 보내도 돈은 음식점별로 각각 주고받아요.

직원은 어디에 있나요? 직원은 5단계에서 음식점 앱에 이름을 눌러 식사만 하면 돼요. 따로 설치할 것은 없고, 가게 태블릿에서 내 잔액을 직접 확인하고 사용 요청도 할 수 있어요. 내 폰에서 따로 적어 두고 싶으면 직원용(베타)을 쓸 수 있어요.

자주 묻는 질문

저는 음식점 사장님·공공기관 담당자(서무)·직원 중 어디에 해당하나요?

음식점 사장님은 가게에서 장부를 쓰는 분(음식점 앱), 공공기관 담당자(서무)는 구청 같은 공공기관에서 직원 식대 명단을 음식점에 보내고 선금을 앱 밖에서 음식점에 직접 지급하는 분(담당자 웹), 직원은 그 식당에서 밥을 먹는 분이에요. 직원은 따로 설치할 것이 없고, 가게 태블릿에서 내 잔액 확인·사용 요청을 직접 할 수 있어요. 내 폰에서 따로 적어 두고 싶을 때만 직원용(베타)을 쓰면 돼요.

정말 무료인가요?

네, 완전 무료예요. 현재 무료 파일럿으로 운영 중이고, 이용료나 수수료를 받지 않아요.

이 앱으로 돈이 오가나요?

아니요. 밥장부 안에서는 돈이 오가지 않아요. 결제앱이 아닙니다. 운영자는 자금을 받거나 보관하지 않아요. 누가 얼마를 언제 먹었는지 장부에 기록만 해요. 선금은 선금을 보내는 쪽(공공기관·회사 등)과 음식점이 앱 밖에서 직접 주고받아요.

어떤 기기에 설치하는 게 좋나요?

장부는 설치한 그 기기에 저장돼요. 그래서 사장님 개인 폰보다는 가게에 항상 두는 전용 태블릿(또는 전용 폰)에 설치하는 걸 권장해요. 설치는 홈 화면에 추가한 뒤 ‘밥장부’ 아이콘으로 열어 쓰는 것이에요(아이폰·아이패드는 사파리와 홈 화면 앱의 장부가 따로라서, 처음부터 아이콘으로 시작해요). 손님은 요청을 준비할 수 있고, 사장님이 돌아와 확인·저장해야 기록돼요. 기기를 잃어버릴 때를 대비해 설정의 [장부 지키기]에서 백업도 해 두세요.

손님이 태블릿을 만져도 되나요?

네, 괜찮아요. 태블릿이 잠겨 있을 때(무조작 90초 또는 홈의 [손님 셀프 조회]) 손님에게 열리는 화면에서는 이름 검색 → 본인 확인 → 금액·서명 → 사장님 확인 받기만 할 수 있어요(잔액과 최근 5건도 그 화면에서 볼 수 있어요). 장부 기록·수정과 설정은 사장님 비밀번호(PIN)가 있어야 열려서, 손님 요청만으로 장부가 바뀌지는 않아요. 검색 목록에는 기관·부서와 이름만 나오고, [네, 맞아요]로 이름을 확인하면 잔액이 보여요. 이 이름 확인은 비밀번호 인증이 아니므로 다른 사람의 이름을 선택하지 않도록 가게에서 안내해 주세요. 손님 화면은 30초 동안 아무 조작이 없으면 처음으로 돌아가요(금액을 적어 둔 동안에는 60초를 기다려 줘요 — 최근 내역을 보는 사이에도 적어 둔 금액이 사라지지 않아요).

손님이 금액을 직접 넣으면 위험하지 않나요?

손님이 넣는 것은 요청일 뿐이고 장부에는 남지 않아요. 손님은 잔액을 넘는 금액을 넣을 수 없고, 금액과 서명을 넣고 [사장님 확인 받기]를 누르면 화면에 그 내용이 크게 표시돼요. 사장님이 비밀번호(PIN)를 넣어 금액을 확인·수정한 뒤 저장해야 비로소 장부에 기록돼요(자동 저장은 없어요). 사장님이 금액을 고치면 서명을 다시 받아요. ‘사장님 확인’ 화면은 60초를 기다려 주고 남은 시간을 보여 줘요. 그동안 아무도 누르지 않으면 요청은 사라지고 장부·서버에 아무것도 남지 않아요(요청은 길어도 2분을 넘겨 남지 않아요). 금액을 손님이 정하기 어려우면 [사장님 부르기]만 눌러 사장님에게 넘길 수도 있어요.

폰을 바꾸면 장부가 사라지나요?

장부는 기기 안에 저장돼요. 설정의 [장부 지키기]에서 [지금 백업하기]를 눌러 백업 파일을 카톡·메일로 보내거나 기기에 저장해 두면, 새 기기에서 [되찾기]로 다시 불러올 수 있어요. 암호를 건 백업 파일에는 가게 열쇠도 함께 들어가요. 가게를 등록했다면 서버에도 매주 한 번 암호화해 자동으로 올려 두는데, 서버 백업에는 서명 그림과 전화번호가 빠져요(서명했다는 기록은 남아요). 기기에 저장한 백업 파일은 기기가 고장 나면 함께 사라지니 폰이나 USB로 옮겨 두세요.

앱을 삭제하면 가게 등록도 사라지나요?

아니요. 앱만 지우면 서버의 가게 등록은 그대로 남아요. 공공기관 담당자 화면과 직원용 앱 목록에 가게가 계속 보이고, 다시 설치해도 재등록이 막혀요. 앱을 그만 쓰거나 기기를 바꿀 때는 먼저 음식점 앱 설정의 [자동 등록 중단 (가게 등록 해제)] 또는 [전체 초기화]를 실행해 주세요. 이미 지워 버렸다면 contact@bapjangbu.com 으로 연락 주시면 정리해 드려요.

인터넷이 없어도 되나요?

네. 사용·선금 기록은 인터넷 없이도 돼요. 공공기관 명단 받기·승인, 가게 검색·등록, 서버 백업에는 인터넷이 필요해요. 와이파이가 없는 가게는 한 달에 한 번 [지금 백업하기]로 백업 파일을 남겨 두세요.

구청 같은 공공기관은 어떻게 쓰나요?

공공기관 담당자(서무)가 직원 명단과 금액을 입력해 음식점으로 암호화 전송해요(여러 음식점에 한 번에 보낼 수도 있어요). 음식점 앱에서는 직원 선금대장 등록 → 자동 등록 — 공공기관에서 보낸 명단 받기로 도착하고, 사장님이 확인해 등록하면 식사할 때마다 차감돼요. 선금(돈)은 앱 밖에서 음식점에 직접 지급해요. 앱이 받는 것은 암호화된 직원 명단뿐이에요. 명단은 여러 음식점에 한 번에 보내더라도 선금은 음식점마다 각각 지급해요.

회사(사기업)나 개인 선금도 되나요?

네. 공공기관 명단은 자동으로 받고, 회사·개인 선금은 설정의 수동 등록(한 명씩 · 엑셀 명단 · 빠른 등록)으로 직접 넣으시면 한 장부에서 함께 관리돼요. 직원마다 소속(선택) 칸에 회사 이름을 적거나 개인이면 '개인'이라고 적어 두면 구분해 보기 편해요. 회사에서 엑셀 명단을 받으실 때는 '부서' 칸을 포함해 달라고 하세요.

직원인데 제 잔액을 직접 보고 싶어요.

가장 빠른 방법은 음식점 태블릿이에요 — 잠겨 있는 화면에서 내 이름을 검색하고(초성 가능) [네, 맞아요]를 누르면 내 잔액이 보이는 화면에서 금액·서명까지 바로 할 수 있어요. 지난 최근 5건은 그 화면의 [최근 사용 내역 보기]로 열어 보면 돼요(자세히). 내 폰에서 따로 적어 두고 싶다면 직원용(베타)에 이용 지역만 고르고 자주 가는 음식점을 등록해 선금·사용 내역을 적어 두면 돼요. 회원가입·로그인이 없고 기록은 내 폰에만 저장돼요. 다만 공식 잔액은 음식점 장부가 기준이라, 금액이 다르면 음식점에서 확인해 주세요.

직원 개인정보(이름·전화번호)는 어떻게 다루나요?

명단은 담당자 브라우저에서 암호화되어 해당 음식점만 열 수 있어요. 운영자와 서버는 볼 수 없고, 전화번호는 서버로 보내지 않아요. 직원용 앱은 이름·전화번호를 아예 받지 않아요. 자세한 내용은 개인정보처리방침에 있어요.

의견과 문의

불편한 점, 필요한 기능, 문의 사항을 남겨 주세요.

어떤 분이신가요?

이름·전화번호·거래 내역 등 개인정보는 적지 말아 주세요.

결제앱이 아닙니다. 완전 무료·가입 없음. 밥장부는 기록 도구예요. 운영자는 자금을 받거나 보관·이체·정산하지 않아요.

돈은 앱을 거치지 않아요. 결제(제로페이, 카드 등)는 가게에서 따로 해요. 실제 돈은 선금을 보내는 쪽(공공기관·회사 등)과 음식점이 앱 밖에서 직접 주고받아요.

암호화된 명단은 Cloudflare 기반 중계 서버로 전달될 수 있어요. 서버 장부 백업도 암호화해 보관해요. 자세한 내용은 개인정보처리방침에서 확인해 주세요.
