# 선입금대장 (Prepaid Ledger PWA)

소규모 음식점에서 단체·직원 식대 선입금을 관리하는 오프라인 지원 PWA 앱입니다.

**선금이 들어오는 두 경로** — 공공기관(구청·시청 등) 선금은 담당자(서무)가 보낸 명단이 **자동 등록**으로 들어오고, 회사(사기업)·개인 선금은 사장님이 **수동 등록**으로 직접 입력합니다. 두 경로 모두 한 장부에서 함께 관리되며, 직원마다 `소속`(선택)으로 구분합니다.

## 주요 기능
- 소속·부서별 직원 잔액 관리 (`소속`은 선택 입력 — 회사명 또는 '개인')
- 공공기관 부서 목록 관리 (전국 시도→기관 2단 선택, 직접 입력도 가능)
- 자동 등록: 공공기관 담당자(서무)가 보낸 암호화 명단 수신·승인
- 수동 등록: 한 명씩 · 빠른 등록 · 엑셀 명단(CSV, `소속` 열 선택 지원)
- 식사 사용 시 서명 기반 차감
- 일자별/직원별 거래 이력 조회
- 장부 안전 저장 (엑셀용 CSV — 잔액표에 `소속` 열 포함 + 복원용 JSON)
- 저장한 데이터 복원 (JSON)
- 4자리 PIN 잠금
- 초기 설정 마법사 4단계 (가게 정보 → 우리 가게 등록 → 공공기관 부서 목록 → 연락처·약관 동의)
- Android PWA 설치용 PNG 아이콘 제공

## 사용 방법
브라우저에서 `index.html`을 열거나, 웹 서버에 호스팅하여 사용합니다.

```bash
python -m http.server 8765
```

## 파일 구성
| 파일 | 설명 |
|------|------|
| `index.html` | 앱 전체 (HTML/CSS/JS 단일 파일) |
| `manifest.json` | PWA 매니페스트 |
| `sw.js` | 서비스 워커 (오프라인 캐시) |
| `agency-index.json` | 공공기관 인덱스 (전국 17개 시도 → 기관 2단, `schemaVersion` 2) |
| `agency-depts/{region}.json` | 시도별 기관의 과 단위 부서 목록 (선택한 시도만 lazy 로드) |
| `agency-departments.json` | 레거시 폴백 — 구형 단일 파일(서울시청·25개 구청) 과 목록 |
| `icons/` | Android PWA 설치용 PNG 아이콘 |
