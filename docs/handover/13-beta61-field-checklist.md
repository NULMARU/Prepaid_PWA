# 13. beta.61 현장 점검표와 정식 버전(1.0) 판단 기준

> beta.61(2026-11-22)은 **베타로 배포**하고 두 가게와 실기기에서 확인한 뒤 정식 버전을 정한다(사용자 결정 2026-11-22).
> 이 문서는 "무엇을 확인해야 하는가"와 "언제 1.0이라 부를 수 있는가"의 진실의 원본이다. 남은 문제의 상세는 [09-open-items.md](09-open-items.md).
> 확인한 사람이 `[ ]`를 `[x]`로 바꾸고 날짜·기기·결과를 한 줄로 적는다. 실패하면 그 줄에 증상을 적고 09에 항목을 만든다.

## 1. 정식 버전(1.0)이라 부르기 전에 채워야 하는 것

| # | 조건 | 상태 |
|---|---|---|
| 가 | beta.61 배포 뒤 **2주** 동안 두 가게에서 장부·백업에 문제가 없을 것 | 진행 중(배포일부터) |
| 나 | 아래 2절 **실기기 점검**을 모두 통과(아이폰 포함). 아이폰을 못 보면 "안드로이드 크롬 권장, 아이폰은 시험 중"이라고 밝힌다 | 미완 |
| 다 | 아래 3절 **beta.61 새 기능**이 현장에서 한 번씩 실제로 돌 것 | 미완 |
| 라 | 널리 알리기 전: 가짜 가게 다수 등록의 전체 상한(09 C14), 장애·색인 멈춤을 알 수 있는 점검 습관(주 1회 `bash harness/verify-all.sh`) | 미완 |

버전 이름을 `1.0.0`으로 바꾸는 것은 가·나·다가 끝난 뒤 사용자가 결정한다. 주소·저장 구조는 그대로라 기존 가게는 할 일이 없다.

## 2. 실기기 점검 (한 번도 실물로 확인하지 못한 것)

**아이폰(사파리 → 홈 화면에 추가)**
- [ ] 처음 설정 전에 설치 안내가 먼저 나오고, 홈 화면 아이콘 이름이 '밥장부'다
- [ ] 홈 화면 앱에서 [지금 백업하기] → 파일 저장(파일 앱)과 공유(카톡·메일)가 된다
- [ ] 홈 화면 앱에서 [되찾기] → 백업 파일 고르기 → 암호 → 장부가 돌아온다
- [ ] 사파리 탭에서 만든 장부가 홈 화면 앱에서는 비어 보인다는 안내를 사장님이 이해한다

**안드로이드(크롬·삼성 인터넷)**
- [ ] 크롬에서 [홈 화면에 추가] 버튼 한 번으로 설치되고 주소창 없이 열린다
- [ ] 삼성 인터넷에서 설치 안내가 맞게 나온다
- [ ] 이미 설치한 기기의 아이콘 이름이 '선입금대장' → '밥장부'로 바뀌는 시점(며칠 뒤 / 다시 설치해야 하는지)
- [ ] 태블릿 가로에서 사용 등록 창의 키보드가 서명·버튼을 가리지 않는다
- [ ] 공유 시트로 백업 파일을 카톡 '나에게 보내기'에 보낼 수 있다

**카카오톡 인앱 브라우저**
- [ ] 카톡으로 받은 앱 링크를 누르면 "크롬(사파리)에서 열어 주세요" 안내와 [주소 복사]가 나온다

**두 가게 태블릿**
- [ ] 주소창 없이(설치형) 열리는지. 주소창이 보이면 홈의 설치 안내 띠가 뜨는지와 [이 안내 그만 보기]
- [ ] 설정 > 장부 지키기 상자의 문장(마지막 서버 백업 날짜, 백업 암호 정함 여부)

## 3. beta.61 새 기능 — 현장에서 한 번씩

**가게 찾기(색인)** — 새 가게 설치 때
- [ ] 지역에 구·군을 적고 찾으면 1~3초 안에 결과가 나온다(폰 데이터 연결에서도)
- [ ] "중구"처럼 같은 이름 구는 고르는 칩이 나온다
- [ ] 색인에 없는 이름 → 0건 문구·기준일·[공공데이터에서 다시 찾기]가 나온다
- [ ] 색인으로 고른 가게로 등록이 끝까지 된다(전화 칸은 비어 있고 직접 넣을 수 있다)
- [ ] 배포 다음 주 월요일 뒤 `https://app.bapjangbu.com/storeidx/meta.json`의 `built`가 새 날짜다(주 1회 예약 실행)

**[이력] > [월별]** — 두 가게
- [ ] 이번 달 "쓴 금액"·"들어온 선금"이 사장님이 아는 숫자와 맞다
- [ ] "지금 남은 선금" 전체가 설정 > 직원 목록 관리의 "잔액 합계"와 같다
- [ ] "오래 안 온 손님"에 나온 분이 실제로 60일 넘게 안 온 분이다
- [ ] 거래가 많은 가게에서 탭을 누를 때 느리지 않다

**부서를 옮긴 분** — 다음 달 명단을 받을 때
- [ ] 같은 소속 다른 부서에 같은 이름이 있으면 "부서를 옮긴 분인가요?" 창이 뜬다
- [ ] [다른 사람이에요]가 기본으로 골라져 있고, 사장님이 뜻을 이해한다
- [ ] [옮긴 분이에요]를 고르면 그 직원 카드가 새 부서로 가고 잔액이 이어진다
- [ ] 옮긴 적 없는 평소 명단은 예전과 똑같이 받아진다(창이 뜨지 않는다)

**담당자 인증 90일** — 서무 담당자
- [ ] 한 번 인증한 뒤 창을 닫고 다음 날 열어도 다시 묻지 않는다
- [ ] 화면 위 "○○@기관 으로 인증됨 · [로그아웃]"이 보이고, [로그아웃] 뒤에는 인증을 다시 받는다
- [ ] 기관 PC가 사이트 저장을 막는 경우 "새로 고치면 다시 인증" 안내가 나온다

**밥장부 개인용 앱(옛 직원용)**
- [ ] 예전에 쓰던 폰에서 열면 기록이 그대로 있고 이름이 '밥장부 개인용'이다
- [ ] 홈 맨 위 "공식 잔액은 음식점 태블릿이 기준이에요. / 여기 금액과 잔액은 내가 직접 적는 개인 기록이에요."가 보인다
- [ ] 이용 지역을 정한 뒤 음식점 검색이 바로 된다

## 4. 배포 뒤 운영자가 주기적으로 볼 것
