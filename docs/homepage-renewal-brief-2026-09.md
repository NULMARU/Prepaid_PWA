# bapjangbu.com 홈페이지 리뉴얼 — 작업 지시서 (2026-09-14)

> 이 문서는 **다른 AI 터미널(ChatGPT/Codex)** 에게 리뉴얼을 맡기고, 그 결과를 이 리포의 검증 절차(§6)로 받기 위한 지시서다.
> 지시받은 쪽은 §1~§5를 지키고 §7의 형식으로 결과를 남긴다. 검증·배포는 지시한 쪽(Claude 세션)이 한다.

## 0. 참고 영상과 이번 리뉴얼의 취지
- 참고: YouTube `https://youtu.be/pYK2inPc4E4` — 「AI 티 싹 빼는 단 한 줄, 디자인이 이렇게 달라집니다 | GPT Image 바이브코딩, 클로드, 코덱스」(코딩 수익화 : 투더제이 TTJ).
- 취지: 지금 홈페이지는 구조·내용은 맞지만 **"AI가 만든 랜딩" 티**(균일한 카드 그리드, 밋밋한 그라데이션, 아이콘+제목+설명의 반복, 힘없는 히어로)가 난다. 영상이 말하는 방법(디자인 방향을 한 줄로 못 박는 지시, GPT Image로 만든 진짜 이미지 활용 등)을 **먼저 영상/자막에서 확인해 요약한 뒤** 적용한다. 영상을 볼 수 없으면 사용자에게 핵심 한 줄을 물어보고 시작한다 — 추측으로 진행하지 않는다.

## 1. 바꾸지 말 것 (하드 제약 — 어기면 검증에서 반려)
1. **파일 구조**: `homepage/` 폴더만 건드린다(`index.html`·`_headers`·`og-image.png` + 새 이미지 파일). 다른 폴더(`index.html` 앱, `agency-web/`, `server/`, `docs/`)는 손대지 않는다.
2. **외부 리소스 0건**: `_headers`의 CSP가 외부 폰트·스크립트·CDN·외부 이미지를 막는다. 웹폰트를 쓰려면 `homepage/fonts/`에 파일로 넣는다(라이선스 확인). 프레임워크·빌드 도구 금지 — **정적 HTML+CSS(+아주 적은 인라인 JS)**.
3. **네트워크 호출은 의견 폼 하나뿐**: `POST https://prepaid-relay.sulsul-plus.workers.dev/api/feedback`(기존 코드의 payload·역할 값 그대로). 새 API·분석 스크립트·폼 서비스 금지.
4. **링크 주소 불변**: 음식점 앱 `https://app.bapjangbu.com/`, 담당자 웹 `https://agency.bapjangbu.com`, 직원용(베타) `https://staff.bapjangbu.com/`, 안내서 3종 `https://app.bapjangbu.com/docs/manual-restaurant.html`·`manual-agency.html`·`manual-staff.html`, 개인정보처리방침 `…/docs/privacy.html`, 이용약관 `…/docs/terms.html`, 연락처 `contact@bapjangbu.com`.
5. **표현 금지어**: 결제·충전·포인트·상품권·페이·적립·잔액 충전 같은 **결제 서비스로 오해될 말**. 반드시 함께 말할 것: **"돈은 앱을 거치지 않아요 — 결제(제로페이, 카드 등)는 가게에서 따로 해요"**, **"결제앱이 아닙니다"**, **"완전 무료·가입 없음"**. '초안'·'법률 검토 후 확정' 같은 표현 금지(약관·방침은 확정본, 시행 2026-07-06).
6. **세 주체 구조 유지**: 음식점 사장님 / 공공기관 담당자(서무) / 직원 — 각자 "무엇을 하면 되는지"가 첫 화면에서 갈라져야 한다. 용어는 그대로(‘공공기관 담당자(서무)’, ‘직원 선금대장’, ‘자동 등록/수동 등록’).
7. **내용 보존**: 아래 §2의 섹션·FAQ 13문항·의견 폼은 **내용을 유지**한다(문장은 다듬어도 사실은 바꾸지 않는다). 특히 "앱을 삭제하면 가게 등록도 사라지나요?"(아니요 — 먼저 등록 해제)와 "이 앱으로 돈이 오가나요?"(아니요)는 답의 뜻이 바뀌면 안 된다.
8. **메타·SEO**: `<html lang="ko">`, `<title>`·description·canonical·OG/Twitter 태그 유지(문구 개선 가능). 디자인이 바뀌면 `og-image.png`(1200×630)도 새로 만든다.
9. **접근성(주 사용자 50대 이상 사장님)**: 본문 ≥16px, 버튼 글자 ≥17px, 터치 영역 ≥44px, 본문 대비 4.5:1 이상, 해요체 통일, 한 화면의 주행동은 하나. 자동 재생 영상·움직이는 배경 금지(`prefers-reduced-motion` 존중).
10. **배포는 하지 않는다**(검증 후 이쪽에서 `npx wrangler pages deploy homepage --project-name=bapjangbu-home --branch=main`). git 커밋도 하지 않는다 — 작업 트리에 변경만 남긴다.

## 2. 현재 페이지의 뼈대 (참고 — 순서·구성은 바꿔도 되지만 빠지면 안 되는 것)
- 히어로: 밥장부 = "단체·직원 식대 장부, 수첩 대신 폰으로". 세 주체 버튼(사장님 앱 열기 / 담당자 웹 / 직원용 베타). "가입 절차·비용 없이 바로 시작".
- 5단계 흐름(앱 설치 → 우리 가게 등록 → 담당자가 명단 작성 → 암호화 전달 → 사장님 결제 확인 후 직원 사용 시작).
- 사장님 섹션(처음 설정 4단계·전용 태블릿 비치 권장·손님 셀프 조회), 담당자 섹션, 직원 섹션, 안내서 3장 카드, "돈은 다루지 않아요. 기록만 해요." 안전 섹션, FAQ 13문항, 의견 폼, 푸터(방침·약관·연락처).
- 현재 팔레트: primary `#1e4e86` / accent `#c0894f`(따뜻한 갈색) — 바꿔도 되지만 **의도가 있는 절제된 팔레트**여야 한다.

## 3. 디자인 방향 (권장)
- "AI 랜딩" 클리셰 제거: 보라 그라데이션, 유리 카드, 동일 크기 카드 3열 반복, 아이콘+제목+두 줄 설명의 무한 반복, 스톡 일러스트.
- 대신: **한국 동네 밥집의 온기**(종이 장부·수첩·계산대·밥상)를 GPT Image 등으로 만든 **실제 이미지 1~3장**(웹 최적화 ≤300KB/장, WebP+PNG 폴백 가능, alt 텍스트 필수, `homepage/img/`에 저장), 편집 디자인처럼 **위계가 분명한 타이포**, 여백으로 구분하는 섹션, 진짜 화면 캡처(앱·담당자 웹)를 쓰려면 개인정보 없는 데모 데이터로.
- 히어로 한 줄: 무엇인지(장부), 누구를 위한 것인지(동네 밥집·공공기관 식대), 무엇이 아닌지(결제앱 아님)가 3초 안에 읽혀야 한다.
- 모바일 우선(360·390px)에서 먼저 예쁘고, 데스크톱은 그 다음.

## 4. 작업 순서 (권장)
1. 영상 핵심 요약(3~5줄) → 사용자에게 확인 받기.
2. 디자인 방향 한 줄 + 팔레트·타이포 결정 → 사용자 확인.
3. `homepage/index.html` 리뉴얼(단일 파일 유지 권장), 이미지 생성·최적화, `og-image.png` 갱신.
4. 자체 점검(§6) 후 §7 보고.
