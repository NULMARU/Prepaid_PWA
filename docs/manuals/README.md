# 밥장부 사용자 안내서 (2026-10-03)

최신 HTML과 PDF는 아래에서 함께 관리합니다. HTML을 바꾸면 PDF도 다시 생성해야 합니다.

| 대상 | 웹 원본 | 출력 파일 |
|---|---|---|
| 음식점 사장님 | ../manual-restaurant.html | 밥장부-안내서-음식점-사장님.pdf |
| 공공기관 담당자(서무) | ../manual-agency.html | 밥장부-안내서-기관-담당자-서무.pdf |
| 직원·손님 | ../manual-staff.html | 밥장부-안내서-직원.pdf |
| 가게 태블릿 옆 손님 안내 | ../guest-tablet-guide.html | 밥장부-손님용-태블릿-안내문-A4.pdf |

사용법을 짧게 다시 썼습니다. 사장님 **3쪽**, 담당자 **2쪽**, 직원 **2쪽**이며, 실제 앱·웹을 로컬에서 가상 데이터로 실행한 화면 예시가 들어 있습니다. 웹에서는 이미지를 눌러 크게 볼 수 있습니다.

- 사장님: 매일 쓰기 → 처음 준비·명단 받기 → 장부 보관·도움말.
- 담당자: 기관 인증·가게 확인·명단 작성 → 합계 확인·전송·반영 확인.
- 직원: 식당 태블릿에서 이름·금액·서명 → 사장님 확인. 개인 기록장 설치는 선택으로 분리.

이전의 긴 설명은 `../manual-restaurant-reference.html`, `../manual-agency-reference.html`, `../manual-staff-reference.html`에 보관했습니다. 짧은 안내서에서 필요한 항목으로 연결하며 상세 도움말에도 돌아오는 링크가 있습니다. 홈페이지의 기존 안내서 주소는 유지했습니다.
손님 안내문은 A4 세로 한 장이며, 인쇄 설정에서 A4·실제 크기(100%)로 출력합니다. 브라우저 HTML을 직접 인쇄할 때는 머리말·꼬리말을 끕니다. 흑백으로도 사용할 수 있습니다.

운영 흐름: **손님 이름·소속 확인 → 금액·서명 → 사장님 확인 받기 → 사장님 PIN·확인·저장**.
가게마다 한 기기에 장부를 보관합니다. 이름 확인 버튼은 인증 기능이 아닙니다.

PDF 재생성 도구: harness/export-manual-pdfs.mjs. 브라우저의 기존 작업 공간과 로컬 preview를 사용하며, 내보낸 링크는 운영용 주소로 정규화합니다. 현재 짧은 안내서 3종은 모두 Chrome 인쇄 엔진으로 생성했습니다. 기본 내보내기 대상은 3종이며, 손님용 한 장 안내문을 고쳤을 때만 도구의 roles에 guest를 추가합니다. 화면 확인 없이 발송하지 마세요.
PDF 검증: `uv run --with pymupdf python harness/check-manual-pdfs.py`.

배포 승인 후 홈페이지는 Cloudflare Pages `bapjangbu-home` main, docs는 GitHub Pages main으로 함께 공개합니다. 기존 beta.52의 앱 코드는 보존하고 사장님 상세 도움말에도 최신 가게 검색·명단 알림·열쇠 암호 안내를 병합했습니다. PDF의 beta.51 표시는 화면 예시를 촬영한 기준 버전입니다.

이번 짧은 개정판은 이메일 재발송하거나 Claude에 재검토 요청하지 않았습니다. 앞서 보낸 메일은 이전 긴 안내서 버전입니다.
